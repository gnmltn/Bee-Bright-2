# Bee Bright Tutorial Center — Frontend

Web app for Bee Bright Tutorial Center: landing page, enrollment, and the Parent, Tutor and Admin dashboards.

## Getting started

Requires Node.js and npm.

```sh
npm i
npm run dev      # dev server on http://localhost:8080
npm run build    # production build
npm test         # unit tests (vitest)
```

The API lives in `../backend` (default `http://localhost:5001`).

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
